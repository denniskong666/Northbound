# 向北 Northbound

一款基于 Phaser 3 的俯视角剧情探索游戏。玩家将跟随主角穿梭于老街区、修理厂、屋顶之间，在四章剧情中做出抉择，每一个选择都会留下印记，并最终汇成四种不同的结局。

## 在线游玩

直接访问公开网址即可游玩（无需下载安装）：

**http://northbound-game.surge.sh**

## 故事简介

北方象征着希望与崭新的人生。Elias、Leo、Maya、Noah 与你曾立下约定——一起北上。但当启程之日临近，故土的牵绊、个人的热爱、集体的承诺开始在每个人心里拉扯。你会坚持最初的约定，还是选择留下？又或者，走出一条属于自己的路？

## 玩法

- **移动**：`W` `A` `S` `D` 或方向键
- **奔跑**：长按 `Shift`
- **交互**：靠近发光点按 `E`
- **推进对话**：`空格` 或鼠标点击
- **退出游戏**：`ESC`（淡出返回标题，存档保留）

### 核心系统

- **跨章印记**：每一章的三选一都会生成 A/B/C 印记，叠加影响后续 NPC 对话与支线解锁
- **好感系统**：与 Elias / Maya / Noah / Leo 的好感度贯穿全局
- **四结局分支**：根据全套印记与最高羁绊生成差异化结局画面
- **场景氛围**：Inmost 风格的深沉色调与程序化场景道具

## 四种结局

- **同赴远方**：坚持北上约定，车厢里只有记账本和通行材料
- **故土相守**：留在老街，封存的通行材料收进柜子
- **独行新路**：不依附任何一方，独自开辟新路
- **暂缓前行**：行李半打包，画稿散落，独自沉淀思考

## 本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

## 技术栈

- **引擎**：Phaser 3.80
- **语言**：TypeScript 5
- **构建工具**：Vite 5
- **部署**：Surge

## 项目结构

```
src/
├── config/         # 游戏配置常量
├── data/           # 对话文本、NPC 定义
├── scenes/         # 场景（标题、序章、各章、终章）
├── state/          # 游戏状态、章节管理
├── systems/        # 对话系统、任务系统、场景装饰、选择系统
└── main.ts         # 入口
```

## 操作说明

- `Northbound.bat`：快速启动开发服务器
- `部署游戏.bat`：一键构建并部署到 Surge
- `部署到Surge.bat`：仅部署 dist 目录到 Surge
